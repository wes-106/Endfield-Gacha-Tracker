# Endfield Gacha Tracker (終末地尋訪紀錄終端)

為《明日方舟：終末地》國際服玩家打造的本機尋訪紀錄管理與分析工具，支援 Windows 與 Android。尋訪紀錄主要儲存於使用者裝置，不需要自行架設或使用本專案的雲端資料庫。

---

## 主要功能
* **雙平台支援**：支援 Windows 電腦版與 Android 手機版。
* **多帳號切換**：自動辨識 UID，可多帳號切換互不干擾。
* **資料備份**：支援每次同步後的自動備份與跨設備手動匯出/導入 JSON 檔。
* **輸出圖片**：可將尋訪紀錄輸出成圖片。

---

## 隱私與資訊安全聲明
- **Token 處理機制**：本程式不會刻意將您的登入憑證（Token）寫入本機設定檔、抽卡資料庫或備份檔案。Token 僅在同步過程中暫存於程式記憶體，並透過 HTTPS 傳送至 Gryphline 官方 API，以進行帳號驗證及取得尋訪紀錄。程式不提供 Token 的永久儲存功能。請注意，部分 API 請求會將 Token 作為 URL 查詢參數傳送，仍請妥善保管您的登入憑證。
- **資料儲存與傳輸**：尋訪紀錄、帳號 UID 及使用者設定主要儲存於本機設備，不會上傳至本專案的第三方資料庫。本程式會與 Gryphline 官方 API 通訊，以取得帳號資訊及尋訪紀錄；另外，也會連線至 GitHub 上的遠端字典專案，下載角色、武器及卡池對照資料。遠端字典服務僅用於遊戲資料顯示，不會刻意傳送您的帳號 Token 或尋訪紀錄。
- **本機資料清除**：Windows 電腦版提供清除本機資料功能，可刪除抽卡資料庫、帳號設定及遠端字典快取。此操作不會刪除使用者另外匯出的手動備份及自動備份 JSON 檔案。Android 版本目前不提供此功能。
- **使用者安全須知**：請妥善保管您的 Token，勿將取得的字串截圖分享或張貼於公共論壇，並僅透過官方網頁等正當管道取得登入憑證。備份 JSON 檔案亦包含帳號 UID 與抽卡紀錄，請避免將備份檔公開分享或存放於不可信任的位置。

## 本機開發

如果您希望親自驗證程式碼，或針對不同平台進行編譯，請參考以下步驟：

### 環境要求
- Flutter SDK：需使用包含符合專案 Dart SDK 版本的 Flutter 版本。
- Dart SDK：^3.13.5。
- 若編譯 Windows 版：需安裝 Visual Studio 2022 (包含 C++ 桌面開發工作負載)
- 若編譯 Android 版：需安裝 Android Studio 

### 1. 取得原始碼與依賴套件
```bash
git clone https://github.com/wes-106/Endfield-Gacha-Tracker.git
cd Endfield-Gacha-Tracker
flutter pub get
```

### 2. 程式碼檢查
```bash
flutter analyze
```

### 3. 編譯執行檔
建置 Windows 桌面版 (.exe):

```bash
flutter build windows
```
建置完成的檔案將位於 build\windows\x64\runner\Release\

建置 Android 手機版 (.apk):

```bash
flutter build apk --release
```
建置完成的檔案將位於 build\app\outputs\flutter-apk\

## 遠端字典檔與更新機制
為了在不頻繁更新應用程式 (APP/EXE) 的情況下，動態適配官方最新的卡池與角色圖片，本程式會在執行時，自動從外部專案 [endfield-dictionary](https://github.com/wes-106/endfield-dictionary) 下載以下三份 JSON 字典檔：
1. 角色名稱與圖片對照表
2. 武器名稱與圖片對照表
3. 當期 UP 卡池資訊清單

**本機快取與更新機制：**
為減少網路連線失敗對程式使用的影響，本程式採用「先讀取本機快取，再嘗試遠端更新」的機制：
1. **優先載入快取**：啟動時先讀取設備內保存的 `dictionary_cache.json`，作為目前的字典資料。
2. **嘗試遠端更新**：接著連線至 GitHub，同時下載三份最新字典檔，並進行基本格式驗證。
3. **更新本機快取**：只有在三份字典均成功取得且通過格式驗證後，才會將新資料寫入本機快取。
4. **離線容錯**：若網路連線失敗、下載逾時或遠端資料格式錯誤，程式會保留並使用先前成功儲存的本機快取，不影響既有抽卡紀錄的讀取。

**對程式運作的影響**：
這些字典檔僅用於畫面顯示與資料對應（例如將代碼轉換為角色名稱、角色頭像及卡池 UP 資訊），不參與帳號驗證或抽卡紀錄的儲存與讀取。即使在沒有網路的環境下，只要設備內存在有效的本機字典快取，仍可正常使用上次取得的字典資料。若遊戲推出新卡池時發現新角色圖片或卡池資訊無法正常顯示，通常代表遠端字典尚待更新。待開發者更新 `endfield-dictionary` 倉庫後，程式會在下次成功連線時自動取得最新資料。
